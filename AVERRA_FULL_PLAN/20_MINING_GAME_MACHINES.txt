PURPOSE
Defines machine entities, operations, upgrades, and production rules.

NORMATIVE LANGUAGE
The terms MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, and MAY are used as engineering requirements.

MACHINE MODEL
Machine type, instance ID, level, condition, location, operating mode, energy cost, production interval, queue, upgrade state, and ownership.

SERVER AUTHORITY
Start/stop/upgrade/collect actions are validated server-side.

PRODUCTION
Server computes production based on authoritative time/state; client animates the result.

UPGRADES
Requirements, cost, duration/cooldown, prerequisites, and balance values are data-driven.

ASSET BINDING
Machine visual asset IDs reference the approved asset registry.

IMPLEMENTATION NOTES
This document is a planning/source-of-truth artifact. Concrete library choices, exact endpoint names, provider-specific payload formats, and deployment values may be finalized during implementation only when they preserve the stated invariants and pass the defined verification gates.
