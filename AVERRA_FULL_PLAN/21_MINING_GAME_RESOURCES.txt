PURPOSE
Defines virtual resources and the resource economy.

NORMATIVE LANGUAGE
The terms MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, and MAY are used as engineering requirements.

RESOURCE CATEGORIES
Raw ores/minerals, processed materials, consumables, fuels/energy items, and event resources as configured.

OWNERSHIP
Resource balances are server-authoritative and persisted with transaction/event history sufficient to reconstruct abnormal changes.

VALUATION
Virtual resource value is defined only inside the game economy unless a separate Reward Engine promotion explicitly links it to a funded financial reward.

ANTI-DUPLICATION
Every material increase/decrease is caused by an authoritative event and validated against the current state/version.

EXTENSIBILITY
Resource definitions are configuration-driven and support seasonal/event resources without schema rewrites where feasible.
