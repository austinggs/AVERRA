PRODUCT DEFINITION
Averra is a Nigerian earning and rewards platform that unifies legitimate third-party offers, surveys, tasks, advertising inventory, referrals, gamification, and a native Three.js Mining Game. The complete system is designed for production operation, not a reduced MVP.

NON-NEGOTIABLE LAWS
Financial state is server-authoritative. Every financial mutation creates an immutable ledger event. Frontend state never authorizes money. Provider callbacks are authenticated, validated, and idempotent. Rewards require a traceable funding source or an explicitly configured Averra-funded budget. Reversals are compensating events. Manual payouts are operator-attributed. Automatic crypto payouts use replaceable provider adapters. Mining Game resources are virtual and are not cryptocurrency. The game server is authoritative. Analytics are never financial truth.

PAYMENT MODES
Withdrawals support MINIPAY_MANUAL, BANK_MANUAL, and CRYPTO_AUTOMATIC_DAIMO.
Inbound user funding includes a detailed MANUAL_MINIPAY_CRYPTO flow on Celo with a planning allowlist of USDT, USDC, USDm, and USAT (see doc 84 section 1; only the server-configured active subset is accepted at runtime, and USDm/USAT remain inactive candidates until individually verified); native CELO and unsupported networks/tokens are not accepted. Manual MiniPay deposits require tx-hash submission, independent on-chain verification, and authorized admin confirmation before User Funding Balance credit. Manual modes are processed within 1–7 business days. Manual MiniPay withdrawals require a manually verified MiniPay destination. MiniPay payment operations may use a direct destination or transaction-specific Cash Link where supported. Daimo crypto deposit is a separate inbound flow and requires a user-submitted “Hurry” request before an operational deposit session is created; the design treats the session/address as having a one-hour validity window, subject to provider-side verification at implementation.

USER FUNDING
Averra maintains a separate User Funding Balance for confirmed user-funded deposits. MiniPay deposits require payment verification and authorized admin confirmation before credit. Confirmed deposits may fund supported Mining Game purchases, virtual goods, paid perks, and other platform purchases. Deposited funds are not automatically earned rewards or withdrawable reward liability.

HOW AN AI AGENT CONTINUES WORK
Read this file, then read ARCHITECTURAL_LAWS, SOURCE_INDEX, the relevant system specification, database/API contract, and acceptance criteria. Inspect existing code and tests before editing. Make the smallest coherent change. Do not bypass reward, ledger, fraud, payout, or authority boundaries. Run targeted tests, typecheck, lint, and build as applicable. Update progress notes.

COMPLETION STANDARD
A feature is not “done” because UI exists. It is done when the behavior is implemented end-to-end, authoritative state is correct, failure paths are handled, security controls exist, tests pass, observability exists, documentation is aligned, and acceptance criteria are satisfied.

REVIEWS & COMMUNITY
Averra includes a public Reviews & Community Feedback System. Users can publish 1–5 star ratings, text, and optional images, with threaded public replies that may also contain images. The system is separate from private Support and financial records. Verified Experience indicators reflect underlying user activity but never imply Averra endorsement. AI-generated customer-support replies and AI-authored moderation decisions are not part of the production review/support path.
